## Download & Install

> Setup notes for **Curve Dental** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **Curve Dental** from the Start menu

- Core Curve Dental features on Windows desktop
- Install and configure Curve Dental for daily use
- Import, edit, and export with Curve Dental tools
- Tune settings and profiles inside Curve Dental
- Integrate Curve Dental into your existing workflow
